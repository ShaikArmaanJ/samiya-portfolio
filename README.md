# Samiya Siddiqua S. — AI & Data Science Portfolio

A premium, interactive, and futuristic digital portfolio built for **Samiya Siddiqua S.**, an Artificial Intelligence and Data Science undergraduate. 

Designed to feel like a modern "AI Laboratory," this portfolio showcases her skills, projects, hackathon experience, and academic achievements without any hallucinated data.

## 🚀 Features

- **Dark AI-Lab Aesthetic:** Glassmorphism, subtle glowing nodes, and clean futuristic typography.
- **Interactive AI Assistant:** A client-side, rule-based chat widget that answers recruiter questions using only verified data (Zero hallucination risk).
- **High Performance:** Built with Framer Motion and Tailwind CSS. No heavy 3D libraries.
- **Secure Architecture:** Ready for backend/API expansion, but operates entirely on the client side for maximum speed and security.

## 🛠 Technology Stack

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel (Recommended)

## 📂 Project Structure

The project follows a clean, modular architecture:
- `src/data/portfolioData.ts` — **The Single Source of Truth.** All verified data about Samiya lives here.
- `src/sections/` — Major page blocks (Hero, Skills, Projects, Milestones, Documents, Contact).
- `src/components/` — Reusable UI elements (e.g., the `AIAssistant` widget).
